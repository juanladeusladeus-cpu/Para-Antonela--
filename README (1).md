# ✨ Para Antonela

Una pequeña página web creada con mucho cariño para Antonela. Un detalle familiar para recordarle lo especial, valiosa y capaz que es.

## 💎 Sobre el proyecto

La página contiene:

- Una pantalla de bienvenida.
- Una portada con un mensaje especial.
- Cuatro cartas interactivas con mensajes de cariño.
- Efectos fugaces de brillo al abrir las cartas.
- Una carta personal de su primo.
- Un mensaje para su futuro.
- Una sorpresa interactiva al final.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

Todo está integrado en un solo archivo HTML. No necesita instalar dependencias ni utilizar imágenes externas.

## 📁 Estructura del proyecto

```text
para-antonela/
├── index.html
└── README.md
```

## 🌐 Publicar con GitHub Pages

1. Abre el repositorio en GitHub.
2. Entra en **Settings**.
3. Busca **Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Pulsa **Save**.
7. Espera a que termine la publicación y abre la dirección que GitHub Pages muestra en esa misma sección.

Asegúrate de que `index.html` esté en la raíz del repositorio y que el nombre esté escrito exactamente así.

## ✏️ Personalización

Para cambiar los mensajes, abre `index.html` y edita los textos directamente en el HTML. Los mensajes de las cuatro cartas están en los atributos `data-title` y `data-message` de cada botón con la clase `letter`.
