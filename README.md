# Para Antonela ♡

Página estática hecha con HTML, CSS y JavaScript.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo llamado `para-antonela`.
2. Sube `index.html` y la carpeta `assets` completa (con las dos fotografías).
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`, y guarda.
6. Espera a que GitHub publique el sitio. La dirección será:
   `https://TU-USUARIO.github.io/para-antonela/`

No cambies los nombres ni la ubicación de las imágenes, porque `index.html` las referencia desde `assets/`.
